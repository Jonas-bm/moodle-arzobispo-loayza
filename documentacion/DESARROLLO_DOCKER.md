# Ejecutar con Docker

La guía vigente para instalar una copia nueva está en
[Instalación con Docker](INSTALACION_DOCKER.md).
Incluye preparación de configuración, instalación manual con el asistente,
activación del diseño, cron y conservación de datos.

Para instalar sin Docker, sigue [README.md](../README.md).

Cada persona crea su propia base y cuenta administradora. No se incluyen datos
demo ni se necesitan credenciales del entorno original.
